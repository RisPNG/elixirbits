# About these tests

These tests were generated to help AI coding tools verify JavaScript behaviour during development. Their expectations were inferred from the instructions and implementation available at the time, and may not fully reflect what the author actually expects.

A passing test only confirms the behaviour that it checks. Review those expectations with the author before treating them as requirements. If a test disagrees with the intended behaviour, correct the expectation and implementation as appropriate.

For the test layout, coverage limits, and verification commands, see the [development guide](../../dev/README.md#test-layout-and-expectations).
